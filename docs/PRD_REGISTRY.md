| PRD-001 | 麦当劳点餐助手（Skill + H5） | 面向本人自用／演示，独立交付兼容 WorkBuddy、Codex 的点餐 Skill 与手机 H5。支持即时到店自取、麦乐送以及手动／智能配餐，按整车热量、预算和必选餐品筛选并支持局部替换。普通模式开放全部可售餐品；减脂汉堡强制去酱，黑咖啡可选奶油球。去酱、奶油球及缺少官方数据的餐品均纳入合理热量估算，统一显示约整数千卡。默认自动选择已校验试算后应付最低的可用券方案，允许换券，仅确认无券时不用券。确认后创建订单、前往官方支付，支持恢复待支付记录、查询取餐／配送与取消；超时先核实，失败保留选择，金额变化重新确认。V1.1 补齐实现口径：试算按分、订单按元不统一换算；官方订单状态映射含已评价与餐厅确认配餐中；内置营养基准表素材（官方清单 160 条无编码，同名命中 22/141，套餐 50 项须按组成合计，12 项待核、57 项待补）；减脂范围按门店分类归一（实测汉堡分三类、咖啡类目名为“麦咖啡™”，分类名含换行需归一后再精确匹配）叠加套餐组成校验与商品清单兜底；去酱经特制项取消酱料提交（试算已验证，创建订单待验证）；到店需选堂食或外带（code 取当次试算返回，上海／郑州的外带 code 不同），默认外带；自动选券按固定顺序匹配且单次试算不超过 8 次；账户连接状态按接口返回探测判定；餐具默认需要，外送备注最多 50 字，随单购不纳入首版。本期不含小程序适配、预约、得来速、团餐及多用户体系，具体去酱与支付能力按联调项验证。 | [PRD-001.md](prd/PRD-001.md) |
